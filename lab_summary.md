# Lab Summary — Multi-Provider API Integration

In this lab, I built a Python news summarizer integrating three external APIs: NewsAPI for retrieving articles, OpenAI for generating summaries, and Cohere for sentiment analysis. The application includes provider fallback, retry logic, rate limiting, budget checks, and cost tracking. One important technical challenge was handling different API interfaces, response formats, and error types across providers. I also learned how to test fallback and reliability mechanisms using mocked API responses without making real requests. The final application successfully processed three news articles with an estimated total API cost of $0.001954, and all 13 automated tests passed. A key limitation is that budget tracking currently works only within a single application session, so persistent monitoring would be needed for a more reliable operational solution.
